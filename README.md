# RESPONSEGRID_GALAPAGOS

Configuración local de la plataforma **SOS Galápagos** (fork de ResponseGrid) para la emergencia por inundaciones de El Niño en Galápagos, 2026.

| Qué | Dónde |
|---|---|
| Plataforma (código de la app, despliegue, Caddy) | [mayait/sosgalapagos](https://github.com/mayait/sosgalapagos) → se clona en `app/` |
| **Datos geográficos, clima, estudios y servidores de datos** | **[mayait/sosgalapagos-datos](https://github.com/mayait/sosgalapagos-datos)** (antes en `geodatos/` y `mapas-galapagos/` de este repositorio) |
| Arranque local y datos semilla de la app | [`galapagos/`](galapagos/LEEME.md) |

La historia de `geodatos/` y `mapas-galapagos/` hasta el 2-nov-2026 sigue en este repositorio; desde entonces se trabaja en **sosgalapagos-datos**.
